# Cauldron Crops — Registro de Consolidação da Direção de Arte

Este arquivo registra de onde veio a direção artística consolidada no Prototype 0 e evita duas situações: perder material útil do legado ou voltar a tratar documentos históricos como fonte de verdade atual.

## Fonte legada

Repositório: `LeandroSatsuki/Cauldron-Crops`

## Material consolidado no Prototype 0

### `docs/art/ART_BIBLE.md`
Foi consolidado como princípios visuais amplos. Regras que ainda eram hipóteses continuam explicitamente abertas.

### `docs/art/TERRAIN_LANGUAGE.md`
Foi consolidado como linguagem de terreno, vegetação, densidade, repetição, agricultura, clima, magia e corrupção.

### `docs/art/TERRAIN_BENCHMARK_01.md`
Foi consolidado e atualizado para incorporar a câmera/escala do Prototype 0 e o teste por zoom.

### `docs/art/GOLEM_LANGUAGE.md`
Foi consolidado como linguagem específica dos golems.

### `docs/art/ART_AUDIT_2026-10-05.md`
Não foi copiado como fonte de verdade. Suas conclusões relevantes foram absorvidas nos documentos acima. O audit era um diagnóstico datado do repositório legado, não uma especificação do protótipo.

## Material que permanece deliberadamente no legado

### `docs/ART_HANDOFF.md`
É uma passagem operacional entre o desenvolvimento do projeto antigo e o Antigravity. Não é necessário duplicá-la no Prototype 0 enquanto o novo fluxo de desenvolvimento não tiver a mesma necessidade.

### `docs/AGENT_TEAM.md` e `AGENTS.md`
São regras de operação do projeto legado. Não devem ser copiadas para o protótipo sem necessidade, porque carregariam decisões e responsabilidades específicas de uma estrutura que não é mais a fonte de verdade do Prototype 0.

### `docs/DECISIONS.md`, `CAULDRON_CROPS_CONTEXT_MASTER.md` e demais documentos históricos
Continuam disponíveis no legado para arqueologia e evidência. Não são autoridades sobre o Prototype 0.

## Lacuna preservada

O audit legado registrou uma referência chamada `ART_STYLE_GUIDE.md` que não estava presente no checkout analisado.

Esse arquivo não foi inventado nem reconstruído por inferência.

Caso apareça futuramente, ele deve ser comparado com o Visual Target atual antes de qualquer regra ser promovida.

## Regra de preservação

Nada foi apagado do repositório legado por esta consolidação.

O Prototype 0 recebe somente o conhecimento que continua útil para a nova fase, reorganizado em uma hierarquia simples.

## Autoridade atual

Para arte do Prototype 0:

1. decisão humana mais recente;
2. `docs/art/VISUAL_TARGET_0.md`;
3. especificações especializadas;
4. `docs/art/ART_BIBLE.md`;
5. referências externas;
6. interpretação de ferramentas.

Não consultar o legado como uma segunda fonte de verdade para decisões já consolidadas sem registrar a evidência ou conflito.
